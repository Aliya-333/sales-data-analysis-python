# Sales Data Analysis Using Python 📊

A data analysis project focused on cleaning, exploring, analyzing,
and visualizing sales data using Python.

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Workflow

- Imported and explored raw sales data
- Investigated missing values
- Cleaned and prepared the dataset
- Analyzed product-wise sales
- Calculated total quantity and sales value
- Identified top-selling products
- Analyzed sales trends
- Created data visualizations
- Exported cleaned data and summary results

## Visualizations

The project includes visualizations such as:

- Top products by sales value
- Top products by quantity sold
- Sales trends
- Product rate distribution
- Quantity vs sales value

## Files

- `Sales_Data_Analysis.ipynb` - Complete analysis
- `cleaned_sales_data.csv` - Cleaned dataset
- `product_sales_summary.csv` - Product-level summary

## Learning Outcome

This project helped me gain practical experience in working with
real-world sales data and strengthened my skills in data cleaning,
exploratory data analysis, Pandas, and data visualization.
